# آریوس — ARIOS OS

سامانهٔ مستقل مدیریت پروژه، نیرو، مشتری و پشتیبانی با رابط فارسی، راست‌به‌چپ و ظاهر زغالی و طلایی. اطلاعات نمونه ساختگی است. این پروژه به کد، پایگاه داده، حساب‌ها، سرویس‌ها یا کلیدهای «دکتر من» متصل نیست.

## قابلیت‌ها

- مدیر: تعریف پروژه و نیروی اجرایی، تخصیص مشتری و نیرو، ثبت پیشرفت، کنترل گزارش کار، نرخ ساعتی با تاریخ اثر، موجودی، مصرف تجهیزات، صورت‌حساب و رسید دستی.
- نیروی اجرایی: مشاهدهٔ پروژه‌های تخصیص‌یافته و ارسال گزارش زمان و کار برای تأیید مدیر.
- مشتری: مشاهدهٔ پروژه‌های خود، پیشرفت، اقلام قابل نمایش، هزینه‌ها و صورت‌حساب، پیام و تیکت پشتیبانی.
- پیام‌های پروژه، پیام داخلی برای تیم، تیکت و پاسخ پشتیبانی با کنترل دسترسی در سرور.
- دستیار پروژه: در سرور واقعی و با اتصال اختصاصی ارائه‌دهندهٔ هوش مصنوعی فعال می‌شود. فقط دادهٔ مجاز پروژهٔ انتخاب‌شده را می‌گیرد؛ اگر پاسخ ساختاریافتهٔ مدل نیاز به پشتیبان را اعلام کند، تیکت همان پروژه به‌صورت خودکار ثبت می‌شود. ارسال دوبارهٔ درخواست یکسان تیکت تکراری نمی‌سازد.

درگاه پرداخت آنلاین هنوز متصل نیست. مشتری نمی‌تواند پرداخت موفق ساختگی ثبت کند؛ فقط مدیر می‌تواند رسید پرداخت دستی را ثبت کند. اتصال درگاه، تأیید سروری تراکنش و تنظیمات پذیرنده برای پرداخت واقعی لازم است.

## دو شیوهٔ اجرا

**پیش‌نمایش ایستا:** پوشهٔ `dist` برای بررسی رابط در مرورگر ساخته می‌شود. اطلاعات ساختگی در حافظهٔ محلی همان مرورگر نگهداری می‌شود؛ تغییر نقش ورود امن محسوب نمی‌شود. این حالت حساب واقعی، پایگاه دادهٔ مشترک، پرداخت واقعی یا مدل زندهٔ هوش مصنوعی ندارد. برای بازنشانی دادهٔ نمونه، دادهٔ سایت را از تنظیمات مرورگر پاک کنید.

**سرور Node:** حساب و نشست واقعی، سطح دسترسی سروری، دادهٔ ماندگار SQLite، اعتبارسنجی عملیات و اتصال اختیاری هوش مصنوعی دارد. حالت تولید با پایگاه دادهٔ خالی شروع می‌شود؛ برای نمونهٔ ساختگی باید حالت نمایشی را صریحاً اجرا کنید.

## اجرای محلی

پیش‌نیاز: Node.js نسخهٔ 24 و Python 3 برای بسته‌بندی سورس. وابستگی npm برای اجرای برنامه لازم نیست.

```bash
npm run demo
```

این فرمان حالت نمونه را روی میزبان محلی فعال می‌کند. آدرس نمایش‌داده‌شده در ترمینال را باز کنید و نقش مدیر، نیرو یا مشتری را برای بررسی انتخاب کنید. ورود نمونه فقط در حالت نمایشی و از مبدأ محلی پذیرفته می‌شود.

برای راه‌اندازی حساب‌های واقعی، یک فایل `.env` جدا مخصوص آریوس از الگو بسازید:

```bash
cp .env.example .env
```

مقادیر `ARIOS_BOOTSTRAP_EMAIL` و `ARIOS_BOOTSTRAP_PASSWORD` را برای مدیر اولیه تعیین کنید؛ رمز باید قوی، یکتا و مخصوص آریوس باشد. هیچ رمز یا کلیدی از پروژهٔ دیگر کپی نکنید. سپس:

```bash
npm start
```

نام و توضیح تنظیمات در `.env.example` آمده است. `ARIOS_PUBLIC_ORIGIN` باید با نشانی واقعی برنامه منطبق باشد. فایل `.env` و پایگاه داده را در Git، آرشیو سورس یا پوشهٔ عمومی قرار ندهید. برای مشتری و نیرو از داخل پنل مدیر حساب مستقل بسازید؛ ساخت پروفایل نیرو به‌تنهایی حساب ورود ایجاد نمی‌کند.

## اتصال هوش مصنوعی

فقط متغیرهای اختصاصی `ARIOS_AI_BASE_URL`، `ARIOS_AI_API_KEY` و `ARIOS_AI_MODEL` برای ارائه‌دهندهٔ سازگار استفاده می‌شوند. کلید نمونه یا مشترک در برنامه وجود ندارد. بدون این تنظیمات، دستیار زنده فعال نیست و درخواست سرور خطای صریح می‌دهد؛ پاسخ نمایشی به‌جای مدل واقعی نمایش داده نمی‌شود. اطلاعات پروژه و متن پیام‌ها برای مدل داده محسوب می‌شوند و اجازهٔ اجرای دستور یا دسترسی به پروژهٔ دیگر نمی‌دهند.

## بررسی و ساخت خروجی

```bash
npm test
npm run build:preview
npm run package:source
```

`build:preview` فایل‌های عمومی را به `dist` کپی می‌کند و `preview-config.mjs` همان خروجی را روی `STATIC_PREVIEW = true` قرار می‌دهد. پیکربندی سورس اصلی در حالت سرور باقی می‌ماند. این پیش‌نمایش را با یک میزبان HTTP ایستا باز کنید؛ فایل‌های ماژول را مستقیماً با `file://` باز نکنید.

`package:source` با کتابخانهٔ استاندارد Python آرشیو `../deliverables/ARIOS_OS_source.zip` و نسخهٔ قابل دانلود `dist/downloads/ARIOS_OS_source.zip` را می‌سازد. فقط سورس عمومی، سرور، آزمون‌ها، اسکریپت‌ها و فایل‌های پیکربندی نمونه و مستندات بسته‌بندی می‌شوند. فایل محرمانه، پایگاه داده، خروجی ساخت، پوشهٔ داخلی ابزارها و پیوند نمادین وارد بسته نمی‌شود. اگر پیش‌نمایش را بعد از بسته‌بندی بسازید، آرشیو موجود دوباره در پوشهٔ دانلود خروجی کپی می‌شود.

## میزبانی واقعی

برای نسخهٔ کامل به میزبان Node.js 24، HTTPS، دامنه و دیسک پایدار برای فایل SQLite نیاز است. تنها `public` باید به‌عنوان فایل ایستا سرو شود؛ پوشهٔ سرور، `.env` و داده‌ها عمومی نیستند. پیش از راه‌اندازی حساب‌های واقعی، مبدأ عمومی، رمز مدیر، پشتیبان‌گیری و مسیر دیسک پایدار را تنظیم کنید. میزبانی صرفاً ایستا فقط پیش‌نمایش محلی مرورگر را اجرا می‌کند و سرور واقعی را جایگزین نمی‌کند.

این بسته به‌تنهایی چیزی منتشر نمی‌کند و به GitHub، Vercel یا سرویس خارجی ارسال نمی‌شود.
